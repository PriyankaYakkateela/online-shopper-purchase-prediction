# Dataset Documentation

## Dataset Name

Online Shoppers Purchasing Intention Dataset

## Source

UCI Machine Learning Repository

Dataset URL: https://doi.org/10.24432/C5F88Q

## Dataset Description

This dataset contains 12,330 online shopping sessions collected from an e-commerce website.

It includes 17 predictor variables describing visitor behavior, browsing activity, and session characteristics.

The target variable is `Revenue`, which indicates whether a visitor completed a purchase during the session.

## Target Variable

* `TRUE`: The session resulted in a purchase.
* `FALSE`: The session did not result in a purchase.

## Data Considerations

* The dataset has an imbalanced target distribution.
* Approximately 15.5% of sessions resulted in purchases.
* The study will examine class imbalance during model evaluation.
* The `PageValues` feature will receive special attention because of its relationship to purchasing behavior.

## Download Instructions

Download the dataset from the official UCI Machine Learning Repository.

The original dataset will not be uploaded to this repository. Users should obtain it directly from the official source.

## Research Use

The dataset will be used for exploratory data analysis, preprocessing, supervised machine learning, and model evaluation.
